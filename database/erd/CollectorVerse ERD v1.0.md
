# CollectorVerse ERD v1.0

# Stato Documento

Questo documento definisce la struttura logica delle relazioni tra le entità di CollectorVerse.

L'obiettivo è trasformare il Data Model concettuale in una struttura pronta per la progettazione del database PostgreSQL e dello schema Supabase.

---

# Come leggere questo documento

Relazioni:

1:1 = Uno a Uno

1:N = Uno a Molti

N:N = Molti a Molti

---

# Regole di Modellazione

Le entità del Data Model possono essere classificate come:

## Tabella

Entità che diventeranno una reale tabella database.

Esempio:

- User
- Category
- Item
- MarketplaceListing

## Configurazione

Entità configurabili tramite Dashboard Admin.

Esempio:

- SubscriptionPlan
- Currency
- BadgeCategory

## Enumerazione

Valori che verranno salvati come campi e non come tabelle autonome.

Esempio:

- ListingStatus
- NotificationPriority
- MatchType
