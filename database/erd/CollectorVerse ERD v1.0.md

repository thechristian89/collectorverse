# CollectorVerse ERD v1.0

# Stato Documento

Questo documento definisce le relazioni tra le entità descritte nel CollectorVerse Data Model v1.0.

L'obiettivo è rappresentare la struttura logica della piattaforma prima della progettazione del database PostgreSQL e dello schema Supabase.

---

# Come leggere questo documento

Le relazioni vengono rappresentate nel seguente modo:

1:1
=
uno a uno

1:N
=
uno a molti

N:N
=
molti a molti
