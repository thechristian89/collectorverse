# Cos'è CollectorVerse

CollectorVerse è una piattaforma universale dedicata al collezionismo.

L'obiettivo è permettere ai collezionisti di:

- catalogare
- organizzare
- completare
- condividere
- acquistare
- vendere
- scambiare

qualsiasi tipologia di oggetto collezionabile.
